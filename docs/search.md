# Search and commands

Press **Ctrl+Shift+K**, or click the search box at the top of the window, to open one box that finds everything:

- **Chats**, in every project, with their status.
- **New chat**: start an agent in the selected project.
- **Projects**.
- **Commands**: almost everything Agents Hub can do, such as switching to the dark theme, showing archived chats or exporting your data. The shortcut for each command is shown next to it.
- **Messages**: what you and the agents said in your chats.
- **Archived** chats and projects.

Type a few letters to narrow the list, use **↑** and **↓** to move, **Enter** to open what is highlighted, and **Esc** to close.

If you don't remember how to do something, try searching for it: most actions in this guide can be found by name.
