# Agents Hub user guide

Agents Hub is a desktop app for Linux that gives your coding agents (Claude Code, Codex and Pi) one place to live. Each conversation with an agent is a **chat**, and each chat belongs to a **project**, which is a folder you work in. The agent runs in a real terminal inside the app, so it looks and works exactly as it does in your own terminal.

You can have several agents working at once, in the same project or in different ones, and Agents Hub tells you when one of them finishes or needs you.

## A few words used in this guide

- **Agent**: a coding assistant program, such as Claude Code, Codex or Pi.
- **Project**: a folder on your computer that you add to Agents Hub. Agents you start in it work in that folder.
- **Chat**: one conversation with one agent, inside a project.
- **Session**: the agent's own record of a conversation. A chat can go through several sessions, for example when you clear the conversation and start again.
