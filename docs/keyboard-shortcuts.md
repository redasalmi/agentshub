# Keyboard shortcuts

These shortcuts work anywhere in the app, even while an agent has the keyboard, because they use keys that terminal programs leave alone. Press **Ctrl+Shift+/** in the app to see this list.

## Getting around

| Shortcut | What it does |
| --- | --- |
| Ctrl+Shift+K | Search chats, messages, projects and commands |
| Ctrl+0 | Show the running chats of every project |
| Ctrl+Shift+J | Open the next chat that needs you |
| Alt+1 … Alt+9 | Open a chat by its place in the list (hold Alt to see the numbers) |
| Ctrl+1 … Ctrl+9 | Select a project by its place in the rail (hold Ctrl to see the numbers) |
| Ctrl+, | Open or close the settings |
| Ctrl+Shift+/ | Show the keyboard shortcuts |

## Projects and chats

| Shortcut | What it does |
| --- | --- |
| Ctrl+Shift+O | Add a project |
| Ctrl+Shift+N | Start an agent in the selected project |
| F2 | Rename the chat |
| Ctrl+Shift+A | Archive the chat |
| Ctrl+Shift+I | Close the idle chats |
| Ctrl+Shift+W | Close all the chats |

## In a chat

| Shortcut | What it does |
| --- | --- |
| Ctrl+` | Show or hide the project's shell |
| Ctrl+Shift+H | Show or hide the earlier sessions |
| Ctrl+Shift+C | Copy the selected text |
| Ctrl+Shift+V | Paste |
| Ctrl+scroll | Make the terminals' text bigger or smaller |

## In the "Start a coding agent" window

| Shortcut | What it does |
| --- | --- |
| 1, 2, 3 or ← → | Pick an agent |
| Enter | Start the picked agent |
| Esc | Cancel |

Every other key goes to the agent, so all of its own shortcuts work as usual.
